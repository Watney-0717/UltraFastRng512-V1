BUILD MODEL
-----------
The canonical V1 implementation is a single translation unit and embeds the
V1 Finance Early, Pharma VPop/uncertainty, and portable checkpoint components.
Standalone copies of those component .c files are retained for source
inspection but are not linked separately by the canonical build script.

PUBLIC RELEASE SCOPE
--------------------
This package intentionally contains V1 only. V2 source/binaries, LEGACY and
staging artifacts, and CPU-specific prebuilt binaries are excluded.
The full Deconstruction Book PDF is included separately as documentation.

STATISTICAL QUALIFICATION BOUNDARY
----------------------------------
PractRand, TestU01 / SmallCrush, dieharder, and NIST SP800-22 named-suite
qualification is not claimed by this package. The included MC-quality,
surrogate-battery, and anti-reuse measurements are evidence only for their
stated experimental scope.

ANTI-REUSE DISCLOSURE
---------------------
The included deep audit distinguishes byte-level inequality from reuse of the
underlying scalar Normal starter pool. PaperView views can be deterministic
layouts of the same starter values, and FIXED generation can retain the same
starter across chunks. Therefore logical sample count is not synonymous with
independent sample count.
